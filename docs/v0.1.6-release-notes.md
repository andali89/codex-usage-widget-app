# v0.1.6 — Taskbar Strip and two-row tray hover

## Taskbar Strip

- Select **Taskbar Strip** in **Settings → Display** for a two-row view of your remaining quota and expected resets. The strip fits the visible readings and uses Windows-style typography, aligned percentages, and compact countdowns.
- Show both periods or just the one you need. Choose `5h` and `7d` word labels or circular `5` and `W` badges. Optional micro bars use your quota colors. The bold and higher-contrast options apply to the entire reading.
- The strip can sit inside a horizontal Windows taskbar as a separate app window. In that position it follows the taskbar’s light or dark theme and can show the background through. When the taskbar cannot fit the strip, it docks above it and uses the app theme.
- Choose **Automatic**, **Show**, or **Hide** for the strip border. Windows high contrast keeps an opaque background and a visible outline. Settings shows when Windows or placement prevents transparency.

## System tray hover

- Hovering over the tray icon shows a compact, read-only summary for both quota periods, including remaining quota and expected resets when available. Clicking the icon opens Overview.
- Where the custom hover preview is unavailable, the app uses a Windows tooltip. Stale and missing data remain distinguishable from an exhausted quota.

## Upgrade and validation

Existing settings upgrade to schema 14. The System Tray remains the default mode for new setups. The [Taskbar Strip implementation report](taskbar-strip-implementation-report.md) records the focused tests and isolated Windows checks. Interactive Windows 10 and 11 checks for taskbar placement, Explorer restart, mixed DPI, and accessibility remain open.

This Windows x64 preview requires WebView2 Runtime 120 or newer and a separately installed, signed-in Codex CLI. Windows notification delivery remains unresolved. See the [setup guide and known limitations](../README.md#known-limitations).
