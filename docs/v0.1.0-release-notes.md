# v0.1.0 — Windows x64 public preview

An unofficial Windows desktop utility for viewing Codex remaining quota and expected reset times through a local, signed-in Codex CLI installation.

## Included

- Floating, Screen Edge, System Tray, and Compact HUD display modes.
- Remaining quota, expected reset countdowns, and available reset-credit information when provided by Codex.
- Independent period/countdown choices for Edge and HUD, with grouped settings controls.
- Light, Dark, and Follow Windows themes; position lock and optional launch at sign-in.
- Proxy configuration for the owned Codex process and selectable local configuration storage.
- Improved topmost recovery when switching applications, without requesting foreground focus.

## Install

Download **Codex Usage Widget_0.1.0_x64-setup.exe** and run the per-user installer. Windows x64 and WebView2 Runtime 120 or newer are required. The installer can offer a WebView2 download if it is missing. Install and sign in to the native Codex CLI separately. GitHub's source ZIP/TAR downloads contain source code, not a ready-to-run application.

The widget keeps authentication with Codex. It does not copy credential files, issue inference requests to read quota, or redeem reset credits. Missing or stale data is labeled explicitly; a countdown reaching zero does not confirm quota recovery.

## Known limitations

- Windows notifications remain unresolved. Do not rely on reminder delivery.
- The build is unsigned and may trigger Windows reputation warnings.
- Runtime validation is on Windows 11; Windows 10, accessibility, mixed-DPI monitors, Explorer recovery, and absent-WebView2 installation remain incompletely verified.
- The actual Photos normal-size/maximized topmost reproduction still needs a desktop check. The related app-owned native stacking regression passes.
- Actual proxy traffic routing remains independently unverified.

This prerelease is for evaluation. Use the tray menu to recover hidden widgets or quit the application. Report the app version, Windows version, and reproduction steps with issues; omit credentials, account identifiers, and private usage responses.
