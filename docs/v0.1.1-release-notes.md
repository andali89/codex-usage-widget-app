# v0.1.1 — Defaults update

Published as a [Windows x64 public preview](https://github.com/andali89/codex-usage-widget-app/releases/tag/v0.1.1) on 24 October 2026; local Rust validation is recorded below.

## Changes

- Detail, Compact, and Background refresh cadences now all default to **120 seconds** for fresh or missing settings. Cadences remain configurable, with existing scheduler jitter and battery-saver adjustments.
- The HTTP/HTTPS proxy field shows `Example: http://127.0.0.1:7890` as a placeholder when no proxy is configured. The example is only a hint; the stored default remains empty. Blank continues to use inherited network settings.
- Existing saved proxy and cadence values are preserved on upgrade. To use the new defaults with an existing configuration, clear the proxy and set all three cadences to 120 seconds in Settings.

## Validation and limitations

After correcting a test that assumed the previous Compact cadence default, local Rust formatting and behavioral checks passed: 134 app tests and 3 dependency tests, with the live Codex probe ignored. See the [implementation report](implementation-report.md#release-test-correction--2026-10-24) for commands and local temporary-directory requirements. Frontend compilation, live Codex reads, Windows runtime checks, and a hosted release rerun remain unverified. No v0.1.1 installer or portable archive has been produced locally.

The [v0.1.0 limitations](v0.1.0-release-notes.md#known-limitations) remain: notification delivery is unresolved, builds are unsigned, several Windows runtime scenarios remain incompletely verified, and actual proxy traffic routing is independently unverified. Authentication stays with the local Codex installation.
