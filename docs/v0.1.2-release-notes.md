# v0.1.2 — Widget presets and shared snapping

Source and local builds only; this version has not been packaged or published.

- Six paired Light/Dark presets: Original, Ocean, Forest, Plum, Slate and Amber. Original preserves the v0.1.0 widget frame, gradients and surface colors.
- Optional 5-hour and weekly quota colors use readable boxed swatches. Each preset remembers separate Light/Dark choices. Only the current effective theme is edited; Load preset colors resets that theme’s two choices.
- Appearance and snap-gap edits temporarily update the current widget. Save persists the whole draft; Cancel or leaving Settings restores saved values. Settings no longer contains sample widget previews.
- Placement includes position lock and a shared 0–48 logical px snap gap, default 8, with saved anchor intent across Floating, Screen Edge and HUD.
- Settings schema 7 preserves schema-6 snapping and quota customizations. Unmatched older structural colors remain available as Saved custom appearance. The storage envelope and reminder transaction remain unchanged.
- Native background transparency stays disabled pending composition validation.
- Carries the unreleased v0.1.1 empty proxy default and 120-second refresh defaults. Existing saved proxy and cadence values remain unchanged.

See the [appearance implementation report](widget-appearance-and-snap-implementation-report.md) for current validation and limitations. The [v0.1.0 limitations](v0.1.0-release-notes.md#known-limitations), including unresolved notification delivery and unsigned builds, still apply. No installer or public release has been produced by this change.
