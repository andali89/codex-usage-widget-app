# v0.1.2 — Widget presets and shared snapping

Source and local builds only; this version has not been packaged or published.

- Eleven paired Light/Dark presets: Original, Graphite, Glacier, Matcha, Rosewood, Terracotta, Sapphire, Sunrise, Mint, Orchid and Slate. Original Dark preserves the v0.1.0 widget appearance. Show widget border defaults to On, restoring the earlier theme-specific outlines, and can be turned off across all themes, widget modes, and hover summaries. Internal period separators and widget dimensions stay unchanged; Windows high contrast retains a visible border.
- Optional 5-hour and weekly quota colors offer 24 or more named swatches, including bright yellow and orange, plus the selected preset’s defaults. Each preset remembers separate Light/Dark choices. Indicators retain the selected fill without added outlines; percentage text uses a readable related shade when needed. Only the current effective theme is edited; Load preset colors resets that theme’s two choices.
- Appearance and snap-gap edits temporarily update the current widget. Save persists the whole draft; Cancel or leaving Settings restores saved values. Settings no longer contains sample widget previews.
- Placement includes position lock and a shared 0–48 logical px snap gap, default 8, with saved anchor intent across Floating, Screen Edge and HUD.
- Settings schema 10 preserves earlier snapping, theme selections, custom colors, and saved transparency percentages while adding an enabled border preference. Unmatched older structural colors remain available as Saved custom appearance. The storage envelope and reminder transaction remain unchanged.
- Overview fits its natural content up to 85% of monitor work-area height. Settings retains the current dimensions and scrolls. Manual standard-window resizing is remembered for the session; the popup keeps its own dimensions and cap.
- Widget background transparency is temporarily disabled and its Settings control is hidden. Previously saved percentages remain stored but do not affect rendering, including temporary previews. Rounded native-window boundaries are retained.
- Carries the unreleased v0.1.1 empty proxy default and 120-second refresh defaults. Existing saved proxy and cadence values remain unchanged.

See the [appearance implementation report](widget-appearance-and-snap-implementation-report.md) for current validation and limitations. The [v0.1.0 limitations](v0.1.0-release-notes.md#known-limitations), including unresolved notification delivery and unsigned builds, still apply. No installer or public release has been produced by this change.
